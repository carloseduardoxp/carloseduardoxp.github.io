# Carlos Eduardo de Carvalho Dantas — Academic Website

This repository contains the source code for my personal academic website, hosted with GitHub Pages.

The website was created from the [Academic Pages](https://github.com/academicpages/academicpages.github.io) template, a Jekyll-based GitHub Pages template designed for academic and professional portfolios.

The original template is based on the [Minimal Mistakes Jekyll Theme](https://mmistakes.github.io/minimal-mistakes/).

## Creating Your Own Academic Website

If you would like to create a similar academic website, I recommend starting directly from the official [Academic Pages repository](https://github.com/academicpages/academicpages.github.io).

On the repository page, click **Use this template** and create a repository named:

```text
your-github-username.github.io
```

Then, customize the `_config.yml` file and the Markdown pages with your personal, academic, and professional information.

For complete installation, configuration, and local execution instructions, refer to the documentation provided in the official Academic Pages repository.

## Running This Website Locally

Install the required dependencies:

```bash
bundle install
```

Then start the local Jekyll server:

```bash
bundle exec jekyll serve -l -H localhost
```

The website should be available at:

```text
http://localhost:4000
```
